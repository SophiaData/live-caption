# live-caption · 产品需求（PRD）

> 本文件用老板的语言写，不出现技术术语。老板可以直接改；改完说一句「PRD 更新了」即可，技术合伙人负责把变化落进功能台账。

## 一句话

给爱看外语视频的用户：把电脑正在播放的声音实时变成「原文+译文」双语悬浮字幕，模型服务由用户自己配置，本地软件零内置、零账号。

## 目标用户与场景

- 用户：爱看外语视频（生肉剧集、演讲、教程、直播）的普通用户；愿意动手填一次模型配置的进阶用户
- 场景 1：看英文生肉剧集——希望屏幕上实时出现双语字幕，不用等官方字幕组
- 场景 2：看外语技术演讲/教程——边听边看译文，术语不猜
- 场景 3：听外语直播——字幕跟着说，虽然慢半拍但看得懂

## 必须有（第一版就要）

> 每条写「用户能做到什么」，不写怎么实现。

- 首次打开有配置引导：填「识别服务」和「翻译服务」的地址、密钥、模型名，各有「测试连接」按钮，通过后即可使用
- 打开开关后，电脑正在播放的声音实时变成字幕，出现在一个置顶悬浮小窗里（原文一行、译文一行）
- 悬浮窗可拖到屏幕任意位置、记住位置，字号/透明度可调，不挡操作
- Mac 顶部菜单栏常驻图标：一键开始/停止，点开能看到当前用的模型
- 支持 Mac 和 Windows 双平台（同一套配置界面与体验）；支持系统版本明确标注：macOS 13 Ventura 及以上（免驱动直接用）、Windows 10 及以上；macOS 12 及以下提供「安装免费声卡」的备用方案但不在主支持范围
- 字幕延迟在「说完一句话后约 2 秒内」出现，可跟着正常语速的节目
- Mac 用户无需安装任何驱动：首次使用只弹一次系统标准授权框

## 可以晚（记下来，先不做）

- 字幕历史回看与导出 srt 文件
- 术语表（人名/专有名词固定译法）
- 边说边出的「草稿字幕先显示、说完再修正」效果
- 用量统计（今天用了多少 API 花费）
- 悬浮窗样式主题/字体选择

## 明确不做

> 防止范围膨胀；想改主意先改这里。

- 不内置任何模型或识别能力（不捆绑、不代付、不送额度），全靠用户自己配置 API 或本地服务
- 不做账号/登录/云端同步，一切配置存本地
- 第一版不做视频文件处理（不做上传视频出字幕、不烧录字幕进视频）
- 第一版不做浏览器插件版

## 成功标准

- 我自己日常看英文视频时真的开着它用，字幕跟得上、看得懂，不再去找字幕组

## 参考与口味

- 喜欢的同类产品：类似「直播同传字幕」的体验——字幕像 CC 隐藏字幕一样贴在屏幕上，安静、不抢戏
- 明确讨厌的：需要注册登录才能用；安装包动辄几百 MB；广告与内置推销
